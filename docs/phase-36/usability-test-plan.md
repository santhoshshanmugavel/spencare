## A specific, real question this phase's own product decision raises for real testing

Task 17 ("Ask Spensa something") is the one task most directly informed
by this phase's Home/Spensa decision. A real usability session should
specifically observe: does a first-time user notice the "Ask Spensa"
card on Home unprompted, or does it need to be pointed out? This is the
single most direct, cheap way to validate (or challenge) this phase's
decision to keep Spensa as a linked-to feature rather than the default
landing screen — with real evidence, not another round of reference
re-interpretation.
