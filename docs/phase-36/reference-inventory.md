# Phase 36 — Reference Inventory

## Method and honesty note

The full reference directory (`/Users/santhoshs/Documents/Santhosh/Web
Screen/`) contains 189 PDF files, no `.docx` or `.txt` files. Reading
all 189 at full depth in one phase is not realistic; this inventory
categorizes every file by name and flow, and is explicit about which
ones have actually been opened and read (across this entire engagement,
not just this phase) versus catalogued by filename only. A file listed
here without a "read" note has NOT been content-verified — its category
is inferred from its name, which is a real but weaker form of evidence
than actually opening it.
