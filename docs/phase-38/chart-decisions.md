# Phase 38 — Chart Decisions

No chart was added, removed, or changed this phase. `CashFlowTrendChart`
(Phase 31, ECharts, SVG renderer, Privacy Mode skip-render, accessible
text summary) remains the product's only chart and was not touched.

**Decision**: did not add a second chart this phase. Neither of the two
fixes made (the zero-eligible-accounts guard, the credit-card helper
note) has any chart-shaped need — both are plain-language explanatory
text, which is the correct form for what they communicate (per Section 2
of this phase's own mandate: "does this make the user's job clearer? If
not, don't build it" — a chart would not have made either fix clearer
than the sentence it actually is).

**CARRIED FORWARD, no changes this phase.**
